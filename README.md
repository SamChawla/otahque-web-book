# Django from First Principles to Production — web book

**Read it:** https://otahque.tech

A beginner-first, illustrated book that teaches Django by building **Otahque**, a community
events application, from the first requirement to production. Chapters are published one
at a time; draft chapters are labelled as drafts.

By [Sumit S Chawla](https://www.linkedin.com/in/sumit-s-chawla/).

## Give feedback

Feedback is very welcome — this is where to send it.

- **Something wrong or unclear in a chapter?** [Open chapter feedback](https://github.com/SamChawla/otahque-web-book/issues/new?template=chapter-feedback.yml)
  (typos, mistakes, confusing explanations, exercises, figures, suggestions).
- **Something wrong with the website?** [Report a website problem](https://github.com/SamChawla/otahque-web-book/issues/new?template=website-problem.yml)
  (layout, links, images, progress bar, phone or browser issues).

Each chapter page also has a "Report an issue with this chapter" link that fills in the
chapter for you. You need a free GitHub account to open an issue. Please check
[existing issues](https://github.com/SamChawla/otahque-web-book/issues) first and add to one if it matches.

Please do not include personal information in issues: they are public.

## What is in this repository

`site/` holds the published website exactly as deployed — HTML, CSS, JavaScript, and figures.
It is generated from the book's manuscript, which is maintained separately, so fixes are made
at the source and the site is republished; pull requests to `site/` cannot be merged directly.
