CHAPTER SIX

Creating the project and understanding its files

Sam’s proposed design now needs a place to run. In Chapter 5, we followed an event request on paper. In this chapter, we prepare a separate working folder, install Django, create the project, and open Django’s own development page. That first page proves that the local project can answer a browser; our own Otahque page begins in Chapter 9.

By the end of the chapter, you will be able to:

  • prepare an isolated environment with the book’s exact Python and Django versions;
  • generate a Django project and distinguish it from a Django app;
  • explain the job of each generated project file;
  • start and stop the local development server and recognize its success page;
  • diagnose common setup problems without overwriting your work.

You will produce a small, explained project and a repeatable local startup check. Chapters 1–5 supply the requirements, web vocabulary, Python practice, and proposed architecture. Have the Chapter 4 uv and Python checks working before beginning. This is local development: there are no event records or member accounts yet. Django apps follow in Chapter 7; dependency locking and Git follow in Chapter 8.
