Checkpoint: Quiz and Challenge

Quiz

Que. 2 What does npm ci do that npm install does not?

Flip to check your answerFold answer back

Answer. It installs exactly the versions in package-lock.json, starting from an empty node_modules, and it refuses to run if package.json and the lockfile disagree. npm install may update the lockfile. Use npm ci to reproduce a setup.

Que. 3 Why does the compiled stylesheet have no .navbar rule until a template uses the class?

Flip to check your answerFold answer back

Answer. Tailwind writes rules only for class names it finds in its sources. With source(none), those are the folders named by @source lines, and until a template there contains navbar, nothing asks for the rule.

Que. 4 Why do links need an underline as well as the primary colour?

Flip to check your answerFold answer back

Answer. Preflight removes the browser’s underline, and our link blue measures only 2.40:1 against the body text, below the 3:1 needed when colour alone marks a link. The underline marks links for everyone.

Que. 5 A template writes class="bg-{{ role }}", and role is primary. Why does the element have no background colour?

Flip to check your answerFold answer back

Answer. The compiler reads the template’s text, where bg-primary never appears whole, so it writes no rule for it. Choose between complete class names, such as {% if featured %}bg-primary{% else %}bg-base-100{% endif %}.

Que. 6 In which layer does a utility class sit, and what does that mean for a component’s padding?

Flip to check your answerFold answer back

Answer. In utilities, the last layer, so a utility such as p-4 on an element beats the padding a component sets. daisyUI’s components sit in nested layers beneath the plain utilities for that reason.

Mini-Challenge

Work in a separate copy of your project, so your checkpoint stays as it is.

Que. 7 In the copy, give the empty state a dashed border, so that “no events” never looks like an event. Write the tests first: one that the empty list renders the border-dashed class, and one that the compiled stylesheet has a rule for it.

Flip to check your answerFold answer back

Answer. Add this class at the end of events/tests.py in the copy. It uses patch, views, and finders, which the file already imports:

events/tests.py (challenge copy only)

class EmptyStateTests(SimpleTestCase):
    def test_empty_state_is_dashed(self):
        with patch.dict(
            views.SAMPLE_EVENTS, {}, clear=True
        ):
            response = self.client.get('/events/')
        self.assertContains(response, 'border-dashed')

    def test_stylesheet_defines_dashed(self):
        found = finders.find('otahque/site.css')
        css = Path(found).read_text(encoding='utf-8')
        self.assertTrue(
            '.border-dashed {' in css,
            'site.css has no .border-dashed rule',
        )

Both fail. In the copy’s events/templates/events/list.html, replace the empty state’s two lines with these four:

events/templates/events/list.html (challenge)

      <li class="event-empty card border border-dashed
                 border-base-300 bg-base-100 p-4">
        No sample events yet.
      </li>

Run the tests: the template test passes and the stylesheet test still fails, because the output is stale. Run npm run build, and all 20 tests in the copy pass. border-dashed is a Tailwind utility, so it reaches the output only because a template contains it whole. Leave your main project at 18 tests for Chapter 15.

What We Learned

  • A design system is a small shared vocabulary of tokens, components, and rules that keeps pages consistent as they grow.
  • Node.js runs the build tools; npm pins them in package-lock.json and npm ci reproduces them, as uv does for Python.
  • Tailwind compiles an authored source and the class names in named templates into the ordinary site.css that Django serves.
  • Preflight resets browser defaults, so headings, links, and focus are restored on purpose in the base layer.
  • daisyUI adds components and a theme of named colour roles; their contrast is ours to measure.
  • Layers decide before specificity: base, then components, then utilities.
  • Class names must appear whole in the sources; a stale output is fixed by building, never by editing it.

Git Commit

Check the changes, then stage the new and changed files, in PowerShell, a macOS shell, or Linux/WSL Bash, beside manage.py. The last command prints one line per staged file with the number of lines changed:

Terminal

git status --short
git add .gitignore .node-version
git add package.json package-lock.json
git add static templates events
git diff --cached --stat

The list includes both static/otahque/source.css and the generated site.css, so the project runs without a build on a computer that has no Node.js. node_modules stays out, as do .env and .venv. Then record the commit:

Terminal

git commit -m "Add the Tailwind and daisyUI build"
