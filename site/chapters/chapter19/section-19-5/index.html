Checkpoint: Quiz and Challenge

Quiz

Que. 2 Both filter() and get() are asked for an event titled Nope, and there is none. What does each do?

Flip to check your answerFold answer back

Answer. filter() returns an empty QuerySet, <QuerySet []>, and raises nothing. get() raises Event.DoesNotExist, because it promises exactly one object. Use filter() when “none” is a normal answer, and get(), or get_object_or_404() in a view, when exactly one must exist.

Que. 3 Raj stores the published events in a variable, events. Next he loops over events to collect the titles, and then he calls events.count(). How many queries ran, and why?

Flip to check your answerFold answer back

Answer. One. Storing the QuerySet runs nothing. The loop evaluates it: one query, and the rows are cached. count() on a fully evaluated QuerySet uses the length of its cache instead of asking the database.

Que. 4 The list view filters on status. Why must the detail view filter on status too?

Flip to check your answerFold answer back

Answer. Because a visitor can type any address. If the detail view looked events up by id alone, /events/3/ would show the draft to anyone who guessed its id, even though the list never links to it. Each page that serves visitors enforces the rule itself, and a test proves it for each.

Que. 5 In Step 4, update() on a QuerySet holding only the meetup returned 1. What does update() not do?

Flip to check your answerFold answer back

Answer. It does not call save() on any model, so code in a custom save() does not run, and it does not change the meetup object already in Python, which keeps its old status until refresh_from_db(). It does not validate the value either: update(status='archived') would be stored just as readily.

Mini-Challenge

Que. 6 Sam asks: “Which published events are in Leeds this year, soonest first?” In the shell, without changing any rows, write one QuerySet that answers him, print its titles, and predict, before running it, how many queries printing the titles runs. Then check your prediction with CaptureQueriesContext.

Flip to check your answerFold answer back

Answer. One QuerySet, three conditions, and the model’s order. Here is one session that answers it:

Django shell

>>> from django.test.utils import CaptureQueriesContext
>>> leeds = Event.objects.filter(
...     status=Event.Status.PUBLISHED,
...     location__icontains='leeds',
...     starts_at__year=2026,
... )
>>> with CaptureQueriesContext(connection) as queries:
...     print([event.title for event in leeds])
...
['Python meetup']
>>> len(queries)
1

Several keyword arguments in one filter() must all be true, which SQL writes with AND. icontains matches Leeds Central Library, Room 2, where an exact location='Leeds' would not. No order_by() is needed, because the model’s ordering is soonest first. Building the QuerySet runs nothing, and the list comprehension runs exactly one query. Your answer may differ, for example with location__startswith='Leeds', and still be right if it returns the meetup alone.

What We Learned

  • The ORM translates between model objects and rows: it writes the SQL, sends values as parameters, and builds an object per row.
  • Event.objects is the model’s manager; all(), filter(), exclude(), and order_by() return QuerySets, each a new one.
  • get() returns exactly one object or raises DoesNotExist or MultipleObjectsReturned; filter() returns a QuerySet that may be empty.
  • Field lookups use two underscores, such as title__icontains and starts_at__gte; several conditions in one filter() must all match.
  • A QuerySet runs its query when evaluated, caches the rows, and reuses them; a new QuerySet queries again. CaptureQueriesContext and assertNumQueries count queries.
  • save(), save(update_fields=...), update(), and delete() change rows; none of them validates the values.
  • Public pages filter on the published status in every view, with get_object_or_404() for the detail page, and a test proves the rule for each page.
  • {% timezone %} shows a stored UTC time in the event’s own zone.
  • Code that no longer has a purpose, such as the sample filter, is deleted.
