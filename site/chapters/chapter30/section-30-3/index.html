How We Build It

Start from Chapter 29, in the folder containing manage.py, with your own .env, the locked environment, 257 passing tests, every migration applied, and Sam’s superuser password from Chapter 18. No package is added. The new files are the audit app, three migrations, two templates, a template filter, docs/design/permissions.md, and docs/adr/ADR-004-access-rules.md. The commands are written the same for Windows PowerShell, Git Bash, macOS, Linux, and WSL; the chapter’s checks ran in the first two. Each step with new behaviour writes its tests first and runs them to see them fail. Steps 5 and 6 prove behaviour that already exists, so most of their checks pass at once.

The tests share one new helper from Step 5: in_group() makes a member with a password and puts them in a group. Earlier helpers keep their jobs: member() makes a member holding named permissions, future_draft() a complete draft that starts next week, and action_url() the address of an event action.

The Custom Way

Many tutorials check ownership inside each view, with an if that compares the event with the signed-in user. Save this practice file as s_idor.py beside manage.py, run it with uv run python manage.py shell -c "exec(open('s_idor.py').read())", and delete it. It makes demo members and a draft inside a transaction it rolls back, so your rows are unchanged:

s_idor.py (practice file; delete it afterwards)

from datetime import timedelta

from django.db import transaction
from django.http import Http404, HttpResponse
from django.test import RequestFactory
from django.utils import timezone

from accounts.models import User
from events.models import Event


def edit_by_hand(request, event_id):
    """Check access inside the view, by hand."""
    event = Event.objects.get(pk=event_id)
    if not event.organizer_assignments.filter(
            member=request.user,
            revoked_at__isnull=True).exists():
        raise Http404
    return HttpResponse(f'Edit form for {event.title}')


def copy_by_hand(request, event_id):
    """Show the copy form; its author forgot the check."""
    event = Event.objects.get(pk=event_id)
    return HttpResponse(f'Copy form for {event.title}')


with transaction.atomic():
    sam = User.objects.create_user(
        'sam.demo@example.org', display_name='Sam demo')
    raj = User.objects.create_user(
        'raj.demo@example.org', display_name='Raj demo')
    start = timezone.now() + timedelta(days=7)
    draft = Event.objects.create(
        title='Sam demo draft', starts_at=start,
        ends_at=start + timedelta(hours=2),
        timezone='UTC', location='Leeds', capacity=20)
    draft.add_organizer(sam)
    request = RequestFactory().get('/')
    request.user = raj
    try:
        edit_by_hand(request, draft.pk)
    except Http404:
        print('edit, checked by hand: 404')
    page = copy_by_hand(request, draft.pk)
    print('copy, check forgotten:', page.status_code,
          page.content.decode())
    transaction.set_rollback(True)

Output

edit, checked by hand: 404
copy, check forgotten: 200 Copy form for Sam demo draft

The first view checks, and Raj gets 404. The second, written later by someone in a hurry, does not, and Raj sees Sam’s draft: an IDOR. Nothing in the code looks wrong; the check is simply missing, and no test asked. The Django Way keeps the rule in one model method that every view calls through one shared helper, event_to_manage(), and writes a test for every row of the matrix, so a new page that forgets is caught by the tests, not by Raj.

"""Tests for the audit app."""
from django.contrib.auth.models import AnonymousUser
from django.db import IntegrityError, transaction
from django.test import TestCase
from django.urls import reverse

from accounts.models import User

from .models import AuditEvent, record

Action = AuditEvent.Action


class AuditEventTests(TestCase):
    """Audit rows: what they hold, and that they stay."""

    @classmethod
    def setUpTestData(cls):
        cls.sam = User.objects.create_superuser(
            'sam@example.org', display_name='Sam'
        )

    def test_a_row_names_actor_action_and_target(self):
        row = record(self.sam, Action.JOIN_ORGANIZERS,
                     self.sam, note='by hand')
        self.assertEqual(
            (row.actor, row.action, row.outcome,
             row.target_type, row.target_id, row.detail),
            (self.sam, 'join_organizers', 'allowed',
             'user', self.sam.pk, {'note': 'by hand'}),
        )

    def test_visitors_and_scripts_have_no_actor(self):
        for actor in (AnonymousUser(), None):
            with self.subTest(actor=actor):
                row = record(actor, Action.VIEW_EVENT)
                self.assertIsNone(row.actor)
                self.assertEqual(row.target_type, '')

    def test_outcome_is_allowed_or_refused(self):
        with self.assertRaises(IntegrityError):
            with transaction.atomic():
                AuditEvent.objects.create(
                    action=Action.VIEW_EVENT,
                    outcome='maybe',
                )

    def test_the_admin_page_is_view_only(self):
        row = record(self.sam, Action.VIEW_EVENT)
        self.client.force_login(self.sam)
        name = 'admin:audit_auditevent'
        listing = self.client.get(
            reverse(f'{name}_changelist')
        )
        self.assertContains(listing, 'View an event')
        add = self.client.get(reverse(f'{name}_add'))
        self.assertEqual(add.status_code, 403)
        change = reverse(f'{name}_change', args=[row.pk])
        self.assertNotContains(self.client.get(change),
                               'name="_save"')
        delete = reverse(f'{name}_delete', args=[row.pk])
        response = self.client.post(delete, {'post': 'yes'})
        self.assertEqual(response.status_code, 403)
        self.assertEqual(AuditEvent.objects.count(), 1)

Now the model. Replace audit/models.py with:

audit/models.py

"""The audit trail: who did what, and whether allowed."""
from django.conf import settings
from django.db import models
from django.utils import timezone


class AuditEvent(models.Model):
    """Who did what to which record, and whether allowed.

    Rows are added, never changed.
    """

    class Action(models.TextChoices):
        """What the person tried to do."""

        CREATE_EVENT = 'create_event', 'Create an event'
        VIEW_EVENT = 'view_event', 'View an event'
        EDIT_EVENT = 'edit_event', 'Edit an event'
        PUBLISH_EVENT = 'publish_event', 'Publish an event'
        CANCEL_EVENT = 'cancel_event', 'Cancel an event'
        DELETE_EVENT = 'delete_event', 'Delete a draft'
        COPY_EVENT = 'copy_event', 'Copy an event'
        MANAGE_ORGANIZERS = (
            'manage_organizers', 'Open organizer access'
        )
        ADD_ORGANIZER = 'add_organizer', 'Add an organizer'
        REMOVE_ORGANIZER = (
            'remove_organizer', 'Remove an organizer'
        )
        JOIN_ORGANIZERS = (
            'join_organizers', 'Join the Organizers group'
        )
        LEAVE_ORGANIZERS = (
            'leave_organizers', 'Leave the Organizers group'
        )

    class Outcome(models.TextChoices):
        """Whether Otahque allowed it."""

        ALLOWED = 'allowed', 'Allowed'
        REFUSED = 'refused', 'Refused'

    actor = models.ForeignKey(
        settings.AUTH_USER_MODEL,
        on_delete=models.PROTECT,
        null=True, blank=True,
        related_name='audit_events',
    )
    action = models.CharField(max_length=40, choices=Action)
    outcome = models.CharField(
        max_length=10, choices=Outcome,
        default=Outcome.ALLOWED,
    )
    target_type = models.CharField(max_length=40, blank=True)
    target_id = models.BigIntegerField(null=True, blank=True)
    detail = models.JSONField(default=dict, blank=True)
    created_at = models.DateTimeField(default=timezone.now)

    class Meta:
        ordering = ['-created_at', '-id']
        default_permissions = ['view']
        constraints = [
            models.CheckConstraint(
                condition=models.Q(outcome__in=[
                    'allowed', 'refused',
                ]),
                name='audit_outcome_valid',
                violation_error_message=(
                    'Outcome must be allowed or refused.'
                ),
            ),
        ]

    def __str__(self):
        return f'{self.get_action_display()}: {self.outcome}'


def record(actor, action, target=None,
           outcome=AuditEvent.Outcome.ALLOWED, **detail):
    """Add one audit row.

    Call it inside the action's own transaction, so a failed
    action leaves no row.
    """
    if actor is not None and not actor.is_authenticated:
        actor = None
    return AuditEvent.objects.create(
        actor=actor,
        action=action,
        outcome=outcome,
        target_type=(target._meta.model_name
                     if target is not None else ''),
        target_id=target.pk if target is not None else None,
        detail=detail,
    )

Action lists every action the trail knows, with words an administrator can read. The target is two plain fields, a type such as event and a number, not a foreign key: when a draft is deleted, its records stay, pointing at a number that no longer exists. Chapter 55 shows the generic relation that could replace them, and its costs. default_permissions = ['view'] gives the model only a view permission, so there is no add, change, or delete permission to grant by mistake. record() is the one way the rest of Otahque writes a row; it turns a signed-out visitor into no actor.

from django.contrib import admin

from .models import AuditEvent


@admin.register(AuditEvent)

    """Return the event, if this member may change it.

    A refusal is recorded as an attempt at action.

    event = get_object_or_404(Event, pk=event_id)

    event = event_to_manage(request, event_id,
                            Action.DELETE_EVENT)
    if request.method == 'POST':
        try:

                # Recorded first: deleting clears event.pk.

Common Error: an edit that changed only the location records the times too

Django’s form.changed_data compares what was typed with what the form first showed, field by field. EventForm shows times in the event’s own zone and reads them back in that zone in its own clean(), but each field’s change check sees only the typed time and the stored time in UTC, so for any event outside UTC it reports starts_at and ends_at as changed when they were not. Recording changed_data would fill the trail with changes nobody made. Compare the saved values instead, as event_edit() does with model_to_dict().

Status: Drafted in Chapter 30, for review. Not approved.

# ADR-004: Access rules in model methods and groups

## Status

Proposed, November 2026 (Chapter 30). The choice follows
the user's decisions of 18 November 2026 (Chapter 30
P2-P4); this record is not yet reviewed or accepted.

## Context

Otahque must answer "may this person do this to this
event?" on every page, in the admin, and later in the API.
The answer depends on a role (may organize) and on a
relationship (organizes this event). Django's model
permissions are per model, not per event, and its
ModelBackend returns no permissions for an object.

## Options

- A: model methods on Event (has_organizer,
  is_visible_to, can_be_edited_by), with Django groups
  for roles; every view calls one method.
- B: policy functions in a separate module.
- C: django-rules: predicates behind
  user.has_perm(perm, event).
- D: django-guardian: a permission row per member and
  event.

## Decision

Option A. Groups Organizers and Administrators are
created by a migration; events.manage_organizers guards
the Organizer access page.

- One place to read and test each rule; the matrix in
  docs/design/permissions.md has a test per row.
- has_perm(perm, obj) is not used: Django answers True
  for any active superuser before a backend is asked, so
  C would let every superuser manage every event.
- D would repeat OrganizerAssignment as permission rows.
- Changing a group's permissions needs a migration until
  Chapter 41 adds a command.

## Revisit when

- The API (Chapter 50) needs the rules in a shared
  module (option B).
- Communities (Chapters 67-68) make organizing rights
  per community.
