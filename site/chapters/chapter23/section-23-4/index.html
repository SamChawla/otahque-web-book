Work through Table 23.3 from the folder that holds manage.py. The test rows come first: they hold the admin’s limits in place, whatever rows your database holds.

Restore DJANGO_ADMIN_URL=admin/ straight after the address check. The commands were checked in Windows PowerShell 5.1 and Git Bash, and the browser rows in Microsoft Edge against the development server, with the browser set to the Kolkata time zone to see the admin’s own time note.
