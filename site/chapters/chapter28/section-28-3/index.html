How We Build It

Start from Chapter 27, in the folder containing manage.py, with your own .env, the locked environment, 190 passing tests, every migration applied, the Node.js packages from Chapter 14, and Sam’s superuser password from Chapter 18. No package is added and no migration is made. The new files are accounts/timezones.py, accounts/middleware.py, static/otahque/site.js, events/templates/events/when.html, and docs/design/sessions-and-time-zones.md. The commands are written the same for Windows PowerShell, Git Bash, macOS, Linux, and WSL; the chapter’s checks ran in the first two. Each step with new behaviour writes its tests first and runs them to see them fail. Steps 2 and 5 hold behaviour Django already has, so their tests pass at once.

The Custom Way

Without the session, a remembered filter is often written as a cookie of its own. This illustration is not part of the project:

illustration_only/views.py (not part of the project)

def event_list(request):
    places_only = request.COOKIES.get('places') == '1'
    response = render(request, 'events/list.html', {
        'places_only': places_only,
    })
    if 'places' in request.GET:
        response.set_cookie('places', request.GET['places'],
                            max_age=60 * 60 * 24 * 365)
    return response

It works, and it starts a habit that grows: every preference becomes another cookie with its own name, lifetime, and rules, each one readable and changeable in the browser, and none of them cleared when the person signs out, so the next person at a shared computer inherits them. The Django Way keeps such values in the one session that Django already protects, ends with sign-out, and expires on a schedule.

Step 2: Look at a session

Start the development server with uv run python manage.py runserver, sign in as Sam at http://127.0.0.1:8000/accounts/login/, and open the browser’s developer tools: in Microsoft Edge and Chrome, press F12 and choose Application, then Cookies. You will see sessionid, csrftoken, and, until the next page, messages. Select sessionid: its value is a key, and the HttpOnly and SameSite columns show Django’s defaults.

To see the server’s side, a practice file signs in a demo member with Django’s test client, prints what each side holds, and undoes its work. Save it as s2_session.py beside manage.py, run it with uv run python manage.py shell -c "exec(open('s2_session.py').read())", and delete it:

s2_session.py (practice file; delete it afterwards)

from django.contrib.sessions.models import Session
from django.db import transaction
from django.test import Client
from django.test.utils import setup_test_environment
from django.utils import timezone

from accounts.models import User

setup_test_environment()
PASSWORD = 'a-long-safe-pass-123'
with transaction.atomic():
    User.objects.create_user('demo@example.org', PASSWORD,
                             display_name='Demo')
    web = Client()
    web.post('/accounts/login/', {
        'login': 'demo@example.org', 'password': PASSWORD,
    })
    print('browser holds:', sorted(web.cookies))
    key = web.cookies['sessionid'].value
    print('the key:', len(key), 'random characters')
    row = Session.objects.get(session_key=key)
    print('server holds:', sorted(row.get_decoded()))
    left = row.expire_date - timezone.now()
    days = round(left.total_seconds() / 86400)
    print('the row expires in:', days, 'days')
    transaction.set_rollback(True)

class SessionCookieTests(TestCase):
    """What the session cookie keeps, and when it ends."""

    @classmethod
    def setUpTestData(cls):
        cls.sai = User.objects.create_user(
            'sai@example.org', SAI_PASSWORD,
            display_name='Sai',
        )

    def sign_in(self, **extra):
        """Sign Sai in, with any extra form fields."""
        return self.client.post('/accounts/login/', {
            'login': 'sai@example.org',
            'password': SAI_PASSWORD, **extra,
        })

    def test_the_cookie_is_kept_from_scripts(self):
        response = self.sign_in(remember='on')
        cookie = response.cookies['sessionid']
        self.assertTrue(cookie['httponly'])
        self.assertEqual(cookie['samesite'], 'Lax')
        self.assertEqual(cookie['max-age'], 1209600)
        self.assertFalse(cookie['secure'])

    def test_without_remember_me_it_ends_with_the_browser(
            self):
        cookie = self.sign_in().cookies['sessionid']
        self.assertEqual(cookie['max-age'], '')
        self.assertTrue(self.client.session
                        .get_expire_at_browser_close())

    def test_the_row_holds_the_data(self):
        self.sign_in()
        key = self.client.cookies['sessionid'].value
        row = Session.objects.get(session_key=key)
        data = row.get_decoded()
        self.assertEqual(data['_auth_user_id'],
                         str(self.sai.pk))
        self.assertNotIn(SAI_PASSWORD, str(data))

In events/views.py, replace event_list():

events/views.py (replace event_list)

def event_list(request):
    """List published events; remember the places filter."""
    choice = request.GET.get('places')
    if choice in ('0', '1'):
        # Saved only when the visitor changes the filter.
        request.session['places_only'] = choice == '1'
    places_only = request.session.get('places_only', False)
    now = timezone.now()
    events = Event.objects.published().with_places()
    upcoming = events.upcoming(now)
    if places_only:
        upcoming = upcoming.filter(places_left__gt=0)
    return render(request, 'events/list.html', {
        'upcoming': upcoming,
        'past': events.past(now),
        'now': now,
        'places_only': places_only,
    })

request.session behaves like a dictionary. The view writes to it only when places is 0 or 1 in the address, so an ordinary visit saves nothing, and reads it with .get(), so a visitor without a session gets False. The filter applies to upcoming events, using Chapter 22’s places_left, which the database counts afresh on every request. Past events are listed as before.

"""Which time zone to show a viewer, and times in it."""
from zoneinfo import ZoneInfo, available_timezones

from django.utils import timezone

from .models import Profile

# The cookie site.js writes with the browser's time zone.
COOKIE = 'otahque_tz'
KNOWN = frozenset(available_timezones())
UTC = ZoneInfo('UTC')


def resolve_timezone(request):
    """Return the zone to show times in.

    The member's profile, then the browser's cookie,
    then UTC.
    """
    user = request.user
    if user.is_authenticated:
        saved = Profile.objects.filter(
            user=user
        ).values_list('timezone', flat=True).first()
        if saved:
            return ZoneInfo(saved)
    name = request.COOKIES.get(COOKIE, '')
    if name in KNOWN:
        return ZoneInfo(name)
    return UTC


def to_user_time(value, request):
    """value, an aware datetime, in the viewer's zone."""
    zone = resolve_timezone(request)
    return timezone.localtime(value, zone)

KNOWN is the set of real zone names, built once when the module is loaded, because building it reads hundreds of files. The profile is read with .filter(...).values_list(...).first(), which returns None instead of making a profile, so a page view never writes to the database. to_user_time() is for Python code that needs a time in the viewer’s zone, such as a message; templates get the zone from the middleware of Step 7.

"""Middleware that shows pages in the viewer's zone."""
from django.urls import reverse
from django.utils import timezone

from .timezones import resolve_timezone


class TimezoneMiddleware:
    """Show every page in the viewer's zone.

    The admin is the exception: it stays in UTC (Chapter 23).
    """

    def __init__(self, get_response):
        """Keep the next handler in the chain."""
        self.get_response = get_response

    def __call__(self, request):
        """Turn on the viewer's zone for this request."""
        if request.path.startswith(reverse('admin:index')):
            timezone.deactivate()
        else:
            timezone.activate(resolve_timezone(request))
        return self.get_response(request)

SALT = 'otahque.demo'


class SigningTests(SimpleTestCase):
    """Signed values: read, refused if changed, expire."""

    def test_a_signed_value_can_be_read(self):
        value = signing.dumps({'places_only': True},
                              salt=SALT)
        data = value.split(':')[0]
        data += '=' * (-len(data) % 4)
        self.assertEqual(base64.urlsafe_b64decode(data),
                         b'{"places_only":true}')

    def test_a_changed_value_is_refused(self):
        value = signing.dumps({'places_only': True},
                              salt=SALT)
        signature = value.split(':', 1)[1]
        forged = base64.urlsafe_b64encode(
            b'{"places_only":false}'
        ).decode().rstrip('=')
        with self.assertRaises(signing.BadSignature):
            signing.loads(f'{forged}:{signature}', salt=SALT)

    def test_an_old_value_expires(self):
        two_minutes_ago = time.time() - 120
        with mock.patch('time.time',
                        return_value=two_minutes_ago):
            value = signing.dumps('x', salt=SALT)
        with self.assertRaises(signing.SignatureExpired):
            signing.loads(value, salt=SALT, max_age=60)
        self.assertEqual(
            signing.loads(value, salt=SALT, max_age=600), 'x'
        )

    def test_a_new_key_needs_the_old_one_as_fallback(self):
        value = signing.dumps('x', salt=SALT)
        old = settings.SECRET_KEY
        new = 'a-new-secret-key-' + 'n' * 40
        with override_settings(SECRET_KEY=new):
            with self.assertRaises(signing.BadSignature):
                signing.loads(value, salt=SALT)
        with override_settings(SECRET_KEY=new,
                               SECRET_KEY_FALLBACKS=[old]):

# Sessions, cookies, and time zones: low-level design

Status: Drafted in Chapter 28, for review. Not approved.

## What each place holds

- sessionid cookie: the session key only. Two weeks;
  until the browser closes for a member who signs in
  without ticking Remember me. HttpOnly, SameSite=Lax.
- django_session row: who is signed in, and
  places_only. Two weeks from the last change.
- messages cookie: signed messages, until shown.
- otahque_tz cookie: the browser's zone, one year.
- Database: events, registrations, and profiles.

Registrations and places left are always read from the
database. The session holds only what may be lost.

## The places filter

- /events/?places=1 saves places_only = True in the
  session; ?places=0 saves False. A plain visit saves
  nothing, so no session is made for a visitor.
- Signing out flushes the session, and the filter with
  it. An expired session is the same as none.

## Time zones

- site.js writes otahque_tz on every page (path /,
  max-age one year, SameSite=Lax; not HttpOnly, not
  signed: the browser writes it).
- accounts.timezones.resolve_timezone(request): the
  profile's zone, then the cookie if it names a real
  zone, then UTC. to_user_time() converts one value.
- accounts.middleware.TimezoneMiddleware, after
  AuthenticationMiddleware, activates that zone; admin
  pages are skipped and stay in UTC (Chapter 23).
- events/when.html shows the venue's time, and "Your
  time" when Event.differs_for() finds another UTC
  offset at the start.
- EventForm and CopyForm clean under UTC (UtcCleaning);
  in_zone() reads typed times in the event's zone.

## Signing

Signed values (the messages cookie, signing.dumps())
can be read but not changed; TimestampSigner adds an
expiry; SECRET_KEY_FALLBACKS keeps old values valid
during a key change. Nothing is encrypted.

- The zone cookie in a consent notice: a later chapter.

Common Error: two scripts declaring the same name

Scripts loaded with ordinary <script> tags share one set of top-level names. Chapter 24’s event-zone.js declares const zone; if site.js declared const zone too, the New event page would stop the second script with a SyntaxError, Identifier 'zone' has already been declared, in the browser’s console, and the form would no longer choose Sam’s time zone for him. That is why site.js uses browserZone. Give each top-level name in a shared script a name no other script uses.
