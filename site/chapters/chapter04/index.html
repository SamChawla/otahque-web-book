CHAPTER FOUR

Python readiness and development tools

Chapter 3 followed a request from a browser to the application and back. We will soon read the Python that handles such requests. Before Django adds its own vocabulary, we need to recognize the language underneath and know how to work with small programs.

By the end of the chapter, you will be able to:

  • trace values, comparisons, and decisions in a short Python example;
  • read collections, loops, functions, imports, and simple classes;
  • use an error message to locate a problem;
  • distinguish an editor, a terminal, and the Python interpreter;
  • run a practice file in an isolated environment and explain its result.

You will produce worked readiness exercises and, in the later tools sections, small practice files and a checked local environment. Basic Python is a prerequisite; this chapter helps you identify and repair gaps. Chapters 1–3 provide the product and web context. The first Django project still begins in Chapter 6.
