Checkpoint: Quiz and Challenge

Quiz

Que. 3 What is the difference between a template and context?

Flip to check your answerFold answer back

Answer. A template describes output structure and instructions. Context supplies the named values used during rendering.

Que. 4 Why is the app name repeated in events/templates/events/list.html?

Flip to check your answerFold answer back

Answer. The inner folder is part of the template name, events/list.html, and helps distinguish it from similarly named templates in other apps.

Que. 5 What does {% empty %} do in the list template?

Flip to check your answerFold answer back

Answer. It supplies output for a for loop when the iterable contains no items.

Que. 6 Does HTML autoescaping make an arbitrary URL or JavaScript snippet safe?

Flip to check your answerFold answer back

Answer. No. HTML escaping is not a substitute for URL validation or the right handling for JavaScript and other output contexts.

Que. 7 Why did the Chapter 10 text assertions need to change?

Flip to check your answerFold answer back

Answer. The list and detail now return HTML from templates rather than the old placeholder and plain-text response. We retain tests for their routes and missing-event behaviour.

Mini-Challenge

Empty the sample list in a separate copy of the project, so that your own checkpoint stays as it is. Work it out before reading the model answer.

Que. 8 In a separate project copy, temporarily make SAMPLE_EVENTS an empty dictionary. What should /events/ show, and what should /events/1/ return? Restore the sample afterwards.

Flip to check your answerFold answer back

Answer. The list should show the message No sample events yet. The detail route still matches /events/1/, but the view finds no entry and returns 404 via Http404. Restore the sample dictionary and rerun uv run python manage.py test events so the next chapter starts at the documented checkpoint.

What We Learned

  • A view supplies a template and context to produce an HTML response.
  • App-scoped template names help distinguish files from different apps.
  • Tags can render a list, an empty case, and links using named routes.
  • Automatic HTML escaping protects ordinary variable output in the appropriate context, with limits.
  • Tests check observed responses; browser inspection checks the rendered page and links.

Git Commit

After checking the changes, stage the four files, in PowerShell, a macOS shell, or Linux/WSL Bash, beside manage.py. Read the staged changes, and press q to leave the listing:

Terminal

git status --short
git add events/tests.py events/views.py
git add events/templates/events/list.html
git add events/templates/events/detail.html
git diff --cached

Keep .env and its secret out of Git. Then record the commit. It stays on your computer; no remote push is needed:

Terminal

git commit -m "Render sample event templates"
