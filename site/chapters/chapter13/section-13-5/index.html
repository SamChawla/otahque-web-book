Checkpoint: Quiz and Challenge

Quiz

Que. 2 How does a static file differ from a media file?

Flip to check your answerFold answer back

Answer. We write static files as part of the site’s code, and they change only when the code does. Media files are uploaded by users at run time and need storage, limits, and checks of their own.

Que. 3 What does {% static 'otahque/site.css' %} produce, and what does it not check?

Flip to check your answerFold answer back

Answer. The address /static/otahque/site.css, built from STATIC_URL and the name. It does not check that the file exists; findstatic does that.

Que. 4 Why is the stylesheet inside an otahque/ folder?

Flip to check your answerFold answer back

Answer. Django serves the first file it finds for a name. A folder named after its owner keeps otahque/site.css from clashing with another app’s site.css.

Que. 5 .site-nav a sets links white, and a later rule a sets them dark. What colour are the navigation links, and why?

Flip to check your answerFold answer back

Answer. White. .site-nav a has a class and an element, so it is more specific than a. Order of appearance only decides between rules of equal specificity.

Que. 6 Why can’t a test simply request /static/otahque/site.css and expect 200?

Flip to check your answerFold answer back

Answer. Tests run with DEBUG set to False, and the development static serving only works when DEBUG is True. We test the link and the finder, and check the served file in the browser.

Mini-Challenge

Work in a separate copy of your project, so your checkpoint stays as it is.

Que. 7 In the copy, give the home page’s introduction a lead class and a rule that makes it slightly larger and muted. Write the test first: it should check that the home page contains the paragraph with that class.

Flip to check your answerFold answer back

Answer. Add this test class at the end of events/tests.py in the copy:

events/tests.py (challenge copy only)

class LeadParagraphTests(SimpleTestCase):
    """The home page opens with a lead paragraph."""

    def test_home_has_lead(self):
        response = self.client.get('/')
        self.assertContains(
            response,
            '<p class="lead">Find a community event'
            ' and see what it is about.</p>',
            html=True,
        )

It fails until the class exists. Then replace events/templates/events/home.html in the copy:

events/templates/events/home.html (challenge)

{% extends "base.html" %}

{% block content %}
  <h1>Welcome to Otahque.</h1>
  <p class="lead">
    Find a community event and see what it is about.
  </p>
{% endblock %}

Add the rule at the end of the copy’s static/otahque/site.css:

static/otahque/site.css (challenge)

.lead {
  font-size: 1.15rem;
  color: #526277;
}

All 17 tests in the copy pass, and #526277 on the page background measures 5.75:1. The name says what the paragraph is, an introduction, not how it looks. Leave your main project at 16 tests for Chapter 14.

What We Learned

  • Static files are part of the site’s code and are sent unchanged; media comes from users and is handled separately.
  • STATICFILES_DIRS adds a project static folder, and a namespace folder keeps names unique.
  • {% static %} writes an address from STATIC_URL; findstatic proves the file exists.
  • The development server serves found files only while DEBUG is True, and tests run with it off.
  • A CSS rule is a selector and declarations; every element is a box of content, padding, border, and margin.
  • The cascade weighs origin and importance, then specificity, then order; developer tools show which rule won.
  • Visible focus and measured contrast are part of styling, not extras.

Git Commit

Check the changes, then stage the new and changed files, in PowerShell, a macOS shell, or Linux/WSL Bash, beside manage.py. Read the staged changes, and press q to leave the listing:

Terminal

git status --short
git add config/settings.py static templates
git add events/tests.py events/templates
git diff --cached

The folder names add every file inside them. Keep .env out of Git, as before. Then record the commit:

Terminal

git commit -m "Add a shared stylesheet through static files"
